# 3D Test 2 - Placing Objects

## About

This is a 3D renderer written in C#. it renders in the console using text.

## Requirements

- .NET 8.0 SDK or newer

Run the application with:

```bash
dotnet run --project "3D Test 2 - Placing Objects"
```

## FPS Counter (Unity)

To display a frames-per-second counter in Unity, attach the `FPSDisplay.cs` script (located in `Assets/Scripts/`) to any active GameObject in your scene, such as the Main Camera. The FPS counter will appear in the top-left corner during Play mode. The `frameRange` field (default: 60) controls how many frames are averaged—higher values provide smoother readings.
