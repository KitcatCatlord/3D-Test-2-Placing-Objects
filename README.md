# 3D Test 2 - Placing Objects

## About

This is a 3D renderer written in C#. it renders in the console using text.

## Requirements

- .NET 8.0 SDK or newer

Run the application with:

```bash
dotnet run --project "3D Test 2 - Placing Objects"
```

## FPS Counter (Unity)

An on-screen FPS counter script is available at `Assets/Scripts/FPSDisplay.cs`. To enable it, attach the script to any active GameObject in your Unity scene (e.g., Main Camera). The FPS counter will appear in the top-left corner during Play mode, showing a running average over the last 60 frames (configurable via the `frameRange` field in the Inspector).
