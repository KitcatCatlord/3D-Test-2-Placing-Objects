# 3D Test 2 - Placing Objects

## About

This is a 3D rendered made in C#.

## Running Tests

Unit tests are located in the `MathHelpers.Tests` project. After restoring
NuGet packages you can execute them with:

```bash
dotnet test
```

The tests validate basic vector and matrix math helpers.
