# 3D Test 2 - Placing Objects

## About

This is a 3D renderer written in C#. it renders in the console using text.

## Requirements

- .NET 8.0 SDK or newer

Run the application with:

```bash
dotnet run --project "3D Test 2 - Placing Objects"
```

## Running Tests

Unit tests are located in the `MathHelpers.Tests` project. After restoring
NuGet packages you can execute them with:

```bash
dotnet test
```

The tests validate basic vector and matrix math helpers.
